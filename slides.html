初學者教學
01 · 生活例子

幫四個人找餐廳

先確認預算與地點，再搜尋選項、核對資訊，最後整理符合條件的結果。每一步的結果都可能改變下一步。

關鍵：Agent 流程可以包含行動與回饋。

02 · 基本概念

Agent 是什麼？

接收目標、取得環境資訊，並選擇行動推進任務的系統。

語言模型可負責理解與決策；工具提供搜尋、計算等能力；結果則成為後續觀察。

來源：Agent 是什麼？ · Xi et al. 2023
03 · 任務循環

目標 → 規劃 → 行動

接著讀取結果，再決定要調整下一步、完成回報，或停止並說明限制。

觀察很重要：搜尋失敗或資料不足時，不應假裝任務已完成。

來源：Agent 如何運作？ · ReAct (Yao et al., 2022)
04 · 工具

模型也能使用外部工具

例如搜尋、計算器、資料庫。Agent 需選擇工具、給出正確輸入，再檢查回傳結果。

工具擴展能力，也讓權限與輸入檢查變得重要。

來源：工具使用 · Toolformer (Schick et al., 2023)
05 · 架構

一個 Agent 或多個？

單一 Agent 通常較簡潔。多個 Agent 可分工，但會增加協調成本及錯誤傳遞的可能。

先問：分工是否能帶來可衡量的改善？

來源：單一與多 Agent · Xi et al. 2023
06 · 可靠性

流暢不等於正確

工具可能失敗、資料可能過期、Agent 可能誤解目標或重複執行。

因此需限制權限與步數、核對來源，並為高影響操作保留人工確認。

來源：評估與安全 · NIST AI RMF
07 · 評估

怎麼知道任務做好了？

檢查任務完成度、正確性、限制條件、工具成功率與所需步數；失敗時也要能停止並說明不確定之處。

指標應對應用途，而非只看回答像不像真人。

08 · 回顧

記住這個循環

目標 → 規劃 → 行動 → 觀察 → 調整或停止

小測驗：搜尋工具回傳的餐廳資訊已過期，Agent 下一步該怎麼做？

參考答案：重新查證或標示無法確認，再更新結果。
